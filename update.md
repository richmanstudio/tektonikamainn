# План модернизации корпоративного портала ООО «ТЕКТОНИКА»

## 🎨 Цель
Создать самый современный и красивый сайт, сохраняя существующую цветовую гамму (синий + желтый акцент).

---

## 📊 Анализ текущего состояния

### Цветовая палитра (сохраняем):
- **Основной цвет**: Синий (`blue-700`, `blue-800`, `blue-900`)
- **Акцентный цвет**: Желтый (`yellow-300`)
- **Фон**: Белый, светло-серый (`gray-50`, `gray-100`)

### Технологический стек:
- React 19 + TypeScript
- Tailwind CSS
- Framer Motion
- React Router
- Lucide React
